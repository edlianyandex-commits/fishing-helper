# 🎣 Fishing Helper

**Авто-рыбалка для WoW и любых игр с рыбалкой.** Программа слушает звук игры,
на всплеск поклёвки мгновенно подсекает и сама перезабрасывает удочку —
даже когда игра свёрнута.

> EN below / английская версия ниже

---

## 🇷🇺 Описание

Fishing Helper делает всю рутину рыбалки за вас: услышал всплеск — подсёк —
перезабросил — ждёт следующую поклёвку. Случайные паузы между забросами
делают поведение естественным.

### Возможности

- ⚡ **Мгновенная подсечка по звуку** — реакция на всплеск быстрее человеческой
- 🖥️ **Ловля в фоне** — нажатия уходят прямо в окно игры, фокус не переключается
- 🎲 **Случайные паузы** — никаких роботных интервалов
- ⏱️ **Расходники по таймеру** — приманки и зелья обновляются сами
- 🦘 **Защита от AFK-кика** — программа «шевелится», если игра молчит
- 🔊 **Три режима звука** — «окно игры», VB-CABLE, весь компьютер:
  слышит только игру, даже когда играет музыка или Discord
- 🎚️ **Автоподбор чувствительности** одной кнопкой
- ⛔ **Аварийный стоп F8** — в любой момент

### Требования

- Windows 10/11 (64-bit), установка не требуется
- Для режима «окно игры»: Windows 10 2004+ или Windows 11

### Настройка (5 минут)

1. Распакуйте архив, запустите `FishingHelper.exe`
2. Активируйте личный ключ из сообщения после покупки
3. Выберите окно игры, укажите клавишу заброса и клавишу подсечки
   *(в WoW подсечка — это «Взаимодействие с целью» / Interact with Target)*
4. Нажмите «Начать ловлю»

### Лицензия

Ключ активации бессрочный и привязывается к одному компьютеру.
Перенос на другой ПК — не чаще 1 раза в 30 дней.

### Где купить

Fishing Helper продаётся на площадке FunPay (поиск: «Fishing Helper» / «бот рыбалки»).
Ссылка на скачивание выдаётся после оплаты вместе с личным ключом.

## 🇬🇧 Description (EN)

Fishing Helper does the boring part of fishing for you: it hears the splash —
hooks — recasts — waits for the next bite. Random pauses between casts make
the behavior look natural.

### Features

- ⚡ **Instant sound-based hookset** — reacts faster than you can see it
- 🖥️ **Background fishing** — keys go straight into the game window, no focus switch
- 🎲 **Random pauses** — no robotic timer-perfect intervals
- ⏱️ **Consumables on schedule** — baits and potions refresh themselves
- 🦘 **AFK-kick protection**
- 🔊 **Three audio modes** — game window, VB-CABLE, whole PC: hears only the
  game even while music or Discord is playing
- 🎚️ **One-click sensitivity tuning**
- ⛔ **Emergency stop on F8**

### Requirements

- Windows 10/11 (64-bit), no installation required
- For the "game window" mode: Windows 10 2004+ or Windows 11

### Setup (5 minutes)

1. Unpack the archive, run `FishingHelper.exe`
2. Activate your personal key from the purchase message
3. Pick the game window, enter the cast key and the hook key
   *(in WoW the hookset is "Interact with Target")*
4. Press "Start fishing"

### License

The activation key is lifetime and binds to one computer.
Moving it to another PC is allowed once every 30 days.

### Where to buy

Fishing Helper is sold on FunPay (search for «Fishing Helper» / «бот рыбалки»).
The download link and your personal key are delivered right after payment.
